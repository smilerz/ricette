# Support

## Community

- **GitHub Discussions** — installation help, user questions, general
  community support.
- **GitHub Issues** — reproducible defects and feature proposals.
- **Private vulnerability reporting** — security issues (see `SECURITY.md`);
  do not report security issues via public Issues or Discussions.

Community support is **best effort**. There is no SLA.

## Hosted

Paid hosted users may receive separate commercial support as part of the
hosted offering. Managed operation (hosting, upgrades, backups,
availability) is itself part of the hosted product's value, independent of
support responsiveness.

## Before opening an issue

- Check existing Issues and Discussions first.
- For self-hosted installs, include your deployment method (container
  image tag), database (SQLite/PostgreSQL), and relevant logs.
- For security vulnerabilities, use private vulnerability reporting
  instead — see `SECURITY.md`.
